
# 🦈 AI Shark Tank

An AI-powered Shark Tank simulator built with Streamlit and OpenAI.

## Features
- Multiple AI investor personas
- Startup pitch evaluation
- Investment offers
- Equity negotiations
- Beautiful Streamlit UI

---

## Setup

### 1. Clone or extract the project

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the app

```bash
streamlit run app.py
```

### 4. Enter your OpenAI API key in the sidebar
